# Standards and scope note

This project is an academic simulation and does not claim IEC or IEEE compliance, certification, or operational suitability.

- **IEC 62443:** concerns cybersecurity for industrial automation and control systems. It may be useful background for a future, explicitly scoped security discussion; this project does not assess conformity.
- **IEC 61850:** concerns communication networks and systems for power utility automation. This project does not implement IEC 61850 protocols or data models.
- **PostgreSQL:** the schema demonstrates relational database mechanisms such as keys, constraints, indexes, views, and triggers. These database features do not establish power-system standards compliance.

If a course requires formal standards mapping, consult the exact official editions and produce a traceability table linking each applicable requirement to an implementation and test. Do not label the current project compliant.
